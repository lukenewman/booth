# Landing page ideas (parked 2026-11-02)

Two self-contained mockups for replacing the current `site/` page. Open either HTML file directly in a browser. Neither is wired into the site.

## Bento grid (`bento-grid.html`)

Edge-to-edge grid of feature tiles with hairline dividers. The first screen is exactly one viewport tall, so every tile is whole at the fold; the rest sit below as square tiles. Clicking a tile flips it to a two-line description.

Earlier rounds tried each tile as a record sleeve with catalog numbers, tracklists and barcodes on the back. Too playful; dropped in favour of the app's own graphite palette and system font.

## Record crate (`record-crate.html`)

Scroll-driven 3D crate. The front sleeve sits pulled up out of the crate; scrolling holds it, then swings it left and past the viewer's shoulder while the next one rises. The headline and download button stay fixed on the left, with a caption for the current feature beneath.

Open questions: scroll-driven vs. autoplay; whether the outgoing sleeve crossing the headline is too much; only still frames at 1440×900 were checked, never the motion itself or phone widths.

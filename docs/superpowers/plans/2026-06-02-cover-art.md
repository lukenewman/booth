# Cover Art Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `thumb_url` and `cover_url` columns to the `release` table, populate them via the Discogs sync and direct-add path, expose them through the query layer, and render them in the release list (40×40 thumbnail) and release detail (full-width cover image).

**Architecture:** Two nullable `TEXT` columns on `release` are the canonical cross-source cache; the Discogs adapter already fetches both URLs — they just need to be routed to the new columns. The UI conditionally renders `<img>` when a URL is present, falling back to the existing styled placeholder div.

**Tech Stack:** Bun, SvelteKit 2 + Svelte 5 (runes), TypeScript, bun:sqlite (sync prepared-statement API).

```ts
db.prepare(
  `UPDATE release
     SET title=?, artist_id=?, year=?, country=?, label=?, catno=?,
```

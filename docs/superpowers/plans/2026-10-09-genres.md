# Genres, styles and smart playlists — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every release a genre (Discogs' 15) and styles, sourced from Discogs, Bandcamp, file tags or a manual edit; make them filterable, colour-coded, and the basis of self-updating smart playlists.

**Architecture:** Each source's evidence is stored raw (Discogs facets, a `bandcamp_item` cache, existing file-tag facets, a manual-tags table). A resolve step after every sync and every manual edit writes one answer per release into `release_genre`, which is the only thing filters, pills and smart playlists read. Style colours live in `style_color`, assigned by frequency, never moved automatically.

**Tech Stack:** SvelteKit 2 + Svelte 5 runes, TypeScript, `bun:sqlite`, hand-rolled SQL migrations. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-09-genres-design.md`

## Global Constraints

- Genres are Discogs' 15, stored in Discogs' casing: `Electronic`, `Rock`, `Funk / Soul`, `Jazz`, `Hip Hop`, `Pop`, `Folk, World, & Country`, `Latin`, `Reggae`, `Blues`, `Classical`, `Stage & Screen`, `Non-Music`, `Children's`, `Brass & Military`.
- Everything genre/style is **displayed lowercase**; stored in Discogs casing.
- Pills are for **styles only**; genre renders as plain lowercase text.
- Resolve precedence, whole set, no merging: **manual → Discogs → Bandcamp → file tags**.
- An untagged release (no genre after resolving) never matches an *exclude* filter.
- Bandcamp album/track pages: fetched at most one every 2 s, back off on 429, cached permanently, never re-fetched except by explicit per-release refetch.
- Hand-made data (manual tags, colour pins, smart-playlist rules) is journaled — `annotations.log` / `playlists.log`.
- No test suite: verification is `bun verify scripts/<name>.ts` (in-memory DB via `runMigrations`) plus `bun check`. **Never run a cleanup that deletes "all X" against `~/.booth/booth.db`** — verify scripts use `:memory:`.
- `bun dev` hot-reloads and its scheduler syncs the real DB mid-task: snapshot `~/.booth/booth.db` with `sqlite3 ~/.booth/booth.db ".backup /tmp/booth-pre-genres.db"` before the first task that changes sync behaviour (Task 2).
- Commit directly to `main` after each task, message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Deliberate deviation from the spec

- **Smart-playlist BPM range is deferred.** BPM is resolved in TypeScript across four providers (`library/bpm.ts`), not a column; filtering it in SQL needs a materialised tempo first. v1 rules are genres, styles and starred-only.

## Review Focus

1. **Genre names containing commas** (`Folk, World, & Country`) in URLs and API params — must round-trip; never comma-join genre lists in a query string. (Task 7 test.)
2. **A file-tag genre like `R&B/Soul` or `Techno (Peak Time / Driving)`** — must map to `Funk / Soul` / `Techno`, never to junk fragments `R`, `B`, `Driving)`. (Task 1 test.)
3. **Bandcamp "Various Artists" compilations and label-page band names** — artist won't match the local album artist; title-only match is allowed only with a host agreement, else unmatched. (Task 4 test.)
4. **Re-sync must not clobber manual tags or colour pins** — a second `resolveGenres` / `assignStyleColors` run leaves them unchanged. (Tasks 3, 6 tests.)
5. **Smart playlists must refuse gig/plain mutations** (add track, sections, crate, target) with 409 so one can never turn into a gig. (Task 10 test.)

```ts
 * Discogs' fixed genre list — the short list every coarse question
 * ("all electronic", "not electronic") runs on. Stored in Discogs' casing so
 * Discogs data matches exactly; shown lowercase everywhere.
 */
export const GENRES = [
  'Electronic', 'Rock', 'Funk / Soul', 'Jazz', 'Hip Hop', 'Pop',
  'Folk, World, & Country', 'Latin', 'Reggae', 'Blues', 'Classical',
  'Stage & Screen', 'Non-Music', "Children's", 'Brass & Military',
] as const;

export function display(name: string): string {
  return name.toLowerCase();
}

/**
 * Twelve hues for style pills, tuned for the dark theme. More than this stop
 * reading as distinct, so styles beyond the top twelve share — see
 * `assignStyleColors` for who gets which.
 */
const HUES = [25, 55, 85, 115, 145, 175, 200, 230, 260, 290, 320, 350];
export const PALETTE = HUES.map((h) => ({
  bg: `oklch(0.33 0.08 ${h})`,
  fg: `oklch(0.90 0.10 ${h})`,
}));
export const PALETTE_SIZE = PALETTE.length;

/** Colour for a style with no assigned slot yet (seen before the next resolve). */
export function fallbackSlot(style: string): number {
  let h = 0;
  for (const c of style) h = (h * 31 + c.charCodeAt(0)) >>> 0;
  return h % PALETTE_SIZE;
}
```

```ts
export interface Vocabulary {
  parents: Map<string, string[]>;
  byKey: Map<string, string>;
}

export function staticVocabulary(): Vocabulary {
  const v: Vocabulary = { parents: new Map(), byKey: new Map() };
  for (const [genre, line] of Object.entries(STYLES)) {
    for (const style of line.split('|')) extendVocabulary(v, style, [genre]);
  }
  return v;
}

export function extendVocabulary(v: Vocabulary, style: string, parents: string[]): void {
  const prev = v.parents.get(style) ?? [];
  v.parents.set(style, [...new Set([...prev, ...parents])]);
  v.byKey.set(matchKey(style), style);
}

const GENRE_KEYS = new Map(GENRES.map((g) => [matchKey(g), g as string]));

/**
 * Map free-form terms (Bandcamp tags, file-tag fragments) into the vocabulary.
 * Anything that is neither a genre nor a known style is dropped — this is what
 * filters out artist names, cities and jokes without a blocklist.
 */
export function mapTerms(terms: string[], v: Vocabulary): { genres: string[]; styles: string[] } {
  const genres = new Set<string>();
  const styles = new Set<string>();
  for (const term of terms) {
    const k = matchKey(term);
    if (!k) continue;
    const g = GENRE_KEYS.get(k) ?? GENRE_ALIASES[k];
    if (g) { genres.add(g); continue; }
    const s = v.byKey.get(k) ?? STYLE_ALIASES[k];
    if (s) styles.add(s);
  }
  return { genres: [...genres], styles: [...styles] };
}

/**
 * A file's genre tag, as candidate terms: the whole value, the value without
 * bracketed groups, and its parts split on , / ; | and spaced &. Splitting on a
 * bare & would turn "R&B" into "R" and "B".
 */
export function splitFileGenre(raw: string): string[] {
  const whole = raw.trim();
  const unbracketed = whole.replace(/\s*[([][^)\]]*[)\]]/g, '').trim();
  const parts = unbracketed.split(/\s*(?:[,/;|]|\s&\s|\s-\s)\s*/).map((p) => p.trim()).filter(Boolean);
  return [...new Set([whole, unbracketed, ...parts].filter(Boolean))];
}

export function mapBandcampGenre(norm: string): string | null {
  return BANDCAMP_GENRES[norm] ?? null;
}

/** Explicit genres win; only when there are none do styles imply them through their parents. */
export function inferGenres(explicit: string[], styles: string[], v: Vocabulary): string[] {
  if (explicit.length) return [...new Set(explicit)];
  const out = new Set<string>();
  for (const s of styles) for (const p of v.parents.get(s) ?? []) out.add(p);
  return [...out];
}
```

```sql
-- Genres and styles. Evidence is stored per source; release_genre holds the
-- one resolved answer that filters, pills and smart playlists read. See
-- docs/superpowers/specs/2026-10-09-genres-design.md.

-- Bandcamp purchases (the fan collection) and what their pages said.
-- Keyed by Bandcamp's own item id so a re-match never re-fetches a page.
CREATE TABLE bandcamp_item (
  item_id          TEXT PRIMARY KEY,           -- "<tralbum_type><tralbum_id>", e.g. a123
  url              TEXT NOT NULL,
  item_type        TEXT NOT NULL CHECK (item_type IN ('album','track')),
  artist           TEXT NOT NULL,              -- band_name
  title            TEXT NOT NULL,              -- item_title
  album_title      TEXT,
  primary_genre    TEXT,                       -- Bandcamp norm_name, e.g. 'electronic'
  tags             TEXT,                       -- JSON array, NULL until the page is fetched
  purchased_at     TEXT,
  page_fetched_at  TEXT,
  page_error       TEXT,
  release_id       TEXT REFERENCES release(id) ON DELETE SET NULL,
  match_state      TEXT NOT NULL DEFAULT 'unmatched' CHECK (match_state IN ('matched','ambiguous','unmatched'))
);
CREATE INDEX idx_bandcamp_item_release ON bandcamp_item(release_id);

-- Hand-set tags. Never touched by sync; journaled to annotations.log.
CREATE TABLE release_tag_manual (
  release_id  TEXT PRIMARY KEY REFERENCES release(id) ON DELETE CASCADE,
  genres      TEXT NOT NULL,                   -- JSON array
  styles      TEXT NOT NULL,                   -- JSON array
  set_at      TEXT NOT NULL
);

-- The resolved answer. Rebuilt by resolveGenres.
CREATE TABLE release_genre (
  release_id  TEXT NOT NULL REFERENCES release(id) ON DELETE CASCADE,
  kind        TEXT NOT NULL CHECK (kind IN ('genre','style')),
  name        TEXT NOT NULL,
  position    INTEGER NOT NULL,
  origin      TEXT NOT NULL CHECK (origin IN ('manual','discogs','bandcamp','file')),
  PRIMARY KEY (release_id, kind, name)
);
CREATE INDEX idx_release_genre_name ON release_genre(kind, name);

-- Style → palette slot. Colours never move on their own; pinned = set by hand.
CREATE TABLE style_color (
  style   TEXT PRIMARY KEY,
  slot    INTEGER NOT NULL,
  pinned  INTEGER NOT NULL DEFAULT 0
);

-- Non-null makes a playlist smart: evaluated on open, never stored as membership.
ALTER TABLE playlist ADD COLUMN rule TEXT;
```

```ts
/**
 * Bandcamp writes "Visit https://<subdomain>.bandcamp.com" into every
 * download's comment. The host is the artist's or label's page — not the
 * album — and it's what breaks ties when matching purchases to releases.
 */
export function bandcampHostFrom(comment: string | undefined): string | undefined {
  const m = comment?.match(/https?:\/\/([a-z0-9-]+\.bandcamp\.com)/i);
  return m ? m[1].toLowerCase() : undefined;
}
```

```ts
import type { Database } from 'bun:sqlite';
import { staticVocabulary, extendVocabulary, mapTerms, splitFileGenre, mapBandcampGenre, inferGenres, type Vocabulary } from './vocabulary';

export type GenreOrigin = 'manual' | 'discogs' | 'bandcamp' | 'file';
interface Answer { genres: string[]; styles: string[]; origin: GenreOrigin }

const parse = <T>(s: string | null | undefined, fallback: T): T => {
  if (s == null) return fallback;
  try { return JSON.parse(s) as T; } catch { return fallback; }
};

/** Static styles plus any style a Discogs release carries, parented by that release's genres. */
export function loadVocabulary(db: Database): Vocabulary {
  const v = staticVocabulary();
  const rows = db.prepare(
    `SELECT g.value AS genres, s.value AS styles
       FROM source_facets s
       JOIN source_facets g ON g.entity_kind='release' AND g.entity_id=s.entity_id AND g.source='discogs' AND g.key='genres'
      WHERE s.entity_kind='release' AND s.source='discogs' AND s.key='styles'`,
  ).all() as { genres: string; styles: string }[];
  for (const r of rows) {
    const genres = parse<string[]>(r.genres, []);
    for (const s of parse<string[]>(r.styles, [])) if (!v.parents.has(s)) extendVocabulary(v, s, genres);
  }
  return v;
}

/**
 * One answer per release; the first source that yields anything wins as a
 * whole set (manual → Discogs → Bandcamp → file tags). Sources are never
 * merged — a Discogs style list plus a label's Bandcamp tags is noisier than
 * either. Rebuilds every release when `releaseIds` is omitted.
 */
export function resolveGenres(db: Database, releaseIds?: string[]): { tagged: number; untagged: number } {
  const v = loadVocabulary(db);
  const scope = releaseIds ? `WHERE id IN (${releaseIds.map(() => '?').join(',')})` : '';
  const ids = (db.prepare(`SELECT id FROM release ${scope}`).all(...(releaseIds ?? [])) as { id: string }[]).map((r) => r.id);
  if (!ids.length) return { tagged: 0, untagged: 0 };

  const manual = new Map((db.prepare(`SELECT release_id, genres, styles FROM release_tag_manual`).all() as { release_id: string; genres: string; styles: string }[])
    .map((r) => [r.release_id, r]));
  const discogs = new Map<string, { genres: string[]; styles: string[] }>();
  for (const r of db.prepare(`SELECT entity_id, key, value FROM source_facets WHERE entity_kind='release' AND source='discogs' AND key IN ('genres','styles')`).all() as { entity_id: string; key: 'genres' | 'styles'; value: string }[]) {
    const d = discogs.get(r.entity_id) ?? { genres: [], styles: [] };
    d[r.key] = parse<string[]>(r.value, []);
    discogs.set(r.entity_id, d);
  }
  const bandcamp = new Map<string, { genre: string | null; tags: string[] }[]>();
  for (const r of db.prepare(`SELECT release_id, primary_genre, tags FROM bandcamp_item WHERE release_id IS NOT NULL`).all() as { release_id: string; primary_genre: string | null; tags: string | null }[]) {
    bandcamp.set(r.release_id, [...(bandcamp.get(r.release_id) ?? []), { genre: r.primary_genre, tags: parse<string[]>(r.tags, []) }]);
  }
  const fileGenres = new Map<string, string[]>();
  for (const r of db.prepare(
    `SELECT t.release_id, f.value FROM track t
       JOIN source_facets f ON f.entity_kind='track' AND f.entity_id=t.id AND f.source='local' AND f.key='genre'
      WHERE t.release_id IS NOT NULL`,
  ).all() as { release_id: string; value: string }[]) {
    fileGenres.set(r.release_id, [...(fileGenres.get(r.release_id) ?? []), parse<string>(r.value, '')]);
  }

  const answer = (id: string): Answer | null => {
    const m = manual.get(id);
    if (m) return { genres: parse<string[]>(m.genres, []), styles: parse<string[]>(m.styles, []), origin: 'manual' };
    const d = discogs.get(id);
    if (d && (d.genres.length || d.styles.length)) return { genres: inferGenres(d.genres, d.styles, v), styles: d.styles, origin: 'discogs' };
    const bc = bandcamp.get(id);
    if (bc) {
      // The primary genre is not a style term: "experimental" would become the
      // Experimental style. It counts only through mapBandcampGenre below.
      const terms = bc.flatMap((b) => b.tags);
      const mapped = mapTerms(terms, v);
      const explicit = [...new Set([...mapped.genres, ...bc.map((b) => (b.genre ? mapBandcampGenre(b.genre) : null)).filter((g): g is string => !!g)])];
      const genres = inferGenres(explicit, mapped.styles, v);
      if (genres.length || mapped.styles.length) return { genres, styles: mapped.styles, origin: 'bandcamp' };
    }
    const f = fileGenres.get(id);
    if (f) {
      const mapped = mapTerms(f.flatMap(splitFileGenre), v);
      const genres = inferGenres(mapped.genres, mapped.styles, v);
      if (genres.length || mapped.styles.length) return { genres, styles: mapped.styles, origin: 'file' };
    }
    return null;
  };

  let tagged = 0;
  const del = db.prepare(`DELETE FROM release_genre WHERE release_id = ?`);
  const ins = db.prepare(`INSERT OR IGNORE INTO release_genre (release_id, kind, name, position, origin) VALUES (?, ?, ?, ?, ?)`);
  db.transaction(() => {
    for (const id of ids) {
      del.run(id);
      const a = answer(id);
      if (!a) continue;
      a.genres.forEach((g, i) => ins.run(id, 'genre', g, i, a.origin));
      a.styles.forEach((s, i) => ins.run(id, 'style', s, i, a.origin));
      if (a.genres.length) tagged++;
    }
  })();
  return { tagged, untagged: ids.length - tagged };
}
```

```ts
export interface BandcampPurchase {
  itemId: string; url: string; itemType: 'album' | 'track';
  artist: string; title: string; albumTitle: string | null;
  primaryGenre: string | null; purchasedAt: string | null;
}

export function parseCollectionItem(raw: Record<string, unknown>, genreNames = BANDCAMP_GENRE_IDS): BandcampPurchase {
  const type = raw.tralbum_type === 't' ? 'track' : 'album';
  const purchased = typeof raw.purchased === 'string' ? new Date(raw.purchased) : null;
  return {
    itemId: `${raw.tralbum_type}${raw.tralbum_id}`,
    url: String(raw.item_url),
    itemType: type,
    artist: String(raw.band_name ?? ''),
    title: String(raw.item_title ?? ''),
    albumTitle: typeof raw.album_title === 'string' && raw.album_title ? raw.album_title : type === 'album' ? String(raw.item_title ?? '') : null,
    primaryGenre: typeof raw.genre_id === 'number' ? genreNames.get(raw.genre_id) ?? null : null,
    purchasedAt: purchased && !isNaN(purchased.getTime()) ? purchased.toISOString() : null,
  };
}

const decode = (s: string) =>
  s.replace(/&amp;/g, '&').replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&lt;/g, '<').replace(/&gt;/g, '>');

/**
 * An album or track page's primary genre and tags. Tags come from the
 * `<a class="tag">` links; the JSON-LD `keywords` list is the fallback (same
 * content, but it would survive a markup change to the links).
 */
export function parseItemPage(html: string): { primaryGenre: string | null; tags: string[] } {
  const genre = html.match(/"genre":"https:\/\/bandcamp\.com\/discover\/([a-z0-9-]+)/)?.[1] ?? null;
  let tags = [...html.matchAll(/<a class="tag"[^>]*>\s*([^<]+?)\s*<\/a>/g)].map((m) => decode(m[1]));
  if (!tags.length) {
    const kw = html.match(/"keywords":(\[[^\]]*\])/)?.[1];
    try { tags = kw ? (JSON.parse(kw) as string[]) : []; } catch { tags = []; }
  }
  return { primaryGenre: genre, tags: [...new Set(tags)] };
}
```

```ts
export async function fetchFanCollection(username: string): Promise<BandcampPurchase[]> {
  const page = await fetch(`https://bandcamp.com/${encodeURIComponent(username)}`, { headers: { 'User-Agent': UA } });
  if (!page.ok) throw new Error(`bandcamp fan page ${page.status}`);
  const html = (await page.text()).replace(/&quot;/g, '"');
  const fanId = html.match(/"fan_id":(\d+)/)?.[1];
  if (!fanId) throw new Error('bandcamp fan id not found — is the profile public?');

  const out: BandcampPurchase[] = [];
  let token = `${Math.floor(Date.now() / 1000) + 86400}::a::`;
  for (let guard = 0; guard < 50; guard++) {
    const res = await fetch('https://bandcamp.com/api/fancollection/1/collection_items', {
      method: 'POST',
      headers: { 'User-Agent': UA, 'Content-Type': 'application/json' },
      body: JSON.stringify({ fan_id: Number(fanId), older_than_token: token, count: 1000 }),
    });
    if (!res.ok) throw new Error(`bandcamp collection ${res.status}`);
    const data = (await res.json()) as { items?: Record<string, unknown>[]; more_available?: boolean; last_token?: string };
    for (const raw of data.items ?? []) out.push(parseCollectionItem(raw));
    if (!data.more_available || !data.last_token) break;
    token = data.last_token;
  }
  return out;
}
```

```ts
import type { Database } from 'bun:sqlite';
import { matchKey } from '$lib/server/library/relink';
import { stripEditionTags } from '$lib/server/library/normalize';
import type { BandcampPurchase } from './bandcampParse';

export interface MatchRelease { id: string; artist: string; title: string; hosts: Set<string> }
export interface MatchTrack { releaseId: string; artist: string; title: string }
export type MatchResult = { state: 'matched'; releaseId: string } | { state: 'ambiguous' | 'unmatched' };

const albumKey = (s: string) => matchKey(stripEditionTags(s));
const push = <K, V>(m: Map<K, V[]>, k: K, v: V) => m.set(k, [...(m.get(k) ?? []), v]);

/**
 * Purchase → release. Conservative like relink: a wrong match files a record
 * under the wrong genre silently; an unmatched one shows up in Untagged.
 *  1. artist + album title; ties broken by the file comment's host.
 *  2. (track purchases) artist + track title → that track's release.
 *  3. album title alone, only when exactly one candidate carries the
 *     purchase's host — covers "Various Artists" and label band names.
 */
export function buildMatcher(releases: MatchRelease[], tracks: MatchTrack[]): (p: BandcampPurchase) => MatchResult {
  const byArtistTitle = new Map<string, MatchRelease[]>();
  const byTitle = new Map<string, MatchRelease[]>();
  const byId = new Map(releases.map((r) => [r.id, r]));
  for (const r of releases) {
    push(byArtistTitle, `${matchKey(r.artist)}|${albumKey(r.title)}`, r);
    push(byTitle, albumKey(r.title), r);
  }
  const trackIndex = new Map<string, MatchRelease[]>();
  for (const t of tracks) {
    const r = byId.get(t.releaseId);
    if (r) push(trackIndex, `${matchKey(t.artist)}|${matchKey(t.title)}`, r);
  }

  return (p) => {
    const host = (() => { try { return new URL(p.url).hostname.toLowerCase(); } catch { return ''; } })();
    const decide = (cands: MatchRelease[] | undefined, requireHost: boolean): MatchResult | null => {
      const uniq = [...new Map((cands ?? []).map((c) => [c.id, c])).values()];
      if (!uniq.length) return null;
      const withHost = uniq.filter((c) => c.hosts.has(host));
      if (requireHost) return withHost.length === 1 ? { state: 'matched', releaseId: withHost[0].id } : withHost.length ? { state: 'ambiguous' } : null;
      if (uniq.length === 1) return { state: 'matched', releaseId: uniq[0].id };
      return withHost.length === 1 ? { state: 'matched', releaseId: withHost[0].id } : { state: 'ambiguous' };
    };
    const album = p.albumTitle ? albumKey(p.albumTitle) : '';
    return (
      (album && decide(byArtistTitle.get(`${matchKey(p.artist)}|${album}`), false)) ||
      (p.itemType === 'track' && decide(trackIndex.get(`${matchKey(p.artist)}|${matchKey(p.title)}`), false)) ||
      (album && decide(byTitle.get(album), true)) ||
      { state: 'unmatched' }
    );
  };
}

/** Local releases (file-backed) with the Bandcamp hosts their tracks' comments name. */
export function loadMatchInputs(db: Database): { releases: MatchRelease[]; tracks: MatchTrack[] } {
  const rows = db.prepare(
    `SELECT r.id, a.name AS artist, r.title FROM release r JOIN artist a ON a.id = r.artist_id
      WHERE r.id IN (SELECT entity_id FROM source_link WHERE entity_kind='release' AND source='local')`,
  ).all() as { id: string; artist: string; title: string }[];
  const hosts = new Map<string, Set<string>>();
  for (const h of db.prepare(
    `SELECT t.release_id, f.value FROM track t
       JOIN source_facets f ON f.entity_kind='track' AND f.entity_id=t.id AND f.source='local' AND f.key='bandcampHost'
      WHERE t.release_id IS NOT NULL`,
  ).all() as { release_id: string; value: string }[]) {
    const s = hosts.get(h.release_id) ?? new Set<string>();
    s.add(JSON.parse(h.value) as string);
    hosts.set(h.release_id, s);
  }
  const tracks = db.prepare(
    `SELECT t.release_id AS releaseId, a.name AS artist, t.title FROM track t JOIN artist a ON a.id = t.artist_id WHERE t.release_id IS NOT NULL`,
  ).all() as MatchTrack[];
  return { releases: rows.map((r) => ({ ...r, hosts: hosts.get(r.id) ?? new Set() })), tracks };
}
```

```ts
import type { Database } from 'bun:sqlite';
import { env } from '$lib/server/env';
import { fetchFanCollection, fetchItemPage } from './bandcamp';
import { parseItemPage, type BandcampPurchase } from './bandcampParse';
import { buildMatcher, loadMatchInputs } from './bandcampMatch';
import { resolveGenres } from './resolve';

export function storePurchases(db: Database, purchases: BandcampPurchase[]) {
  const up = db.prepare(
    `INSERT INTO bandcamp_item (item_id, url, item_type, artist, title, album_title, primary_genre, purchased_at)
     VALUES (?, ?, ?, ?, ?, ?, ?, ?)
     ON CONFLICT(item_id) DO UPDATE SET url=excluded.url, artist=excluded.artist, title=excluded.title,
       album_title=excluded.album_title, primary_genre=COALESCE(bandcamp_item.primary_genre, excluded.primary_genre),
       purchased_at=excluded.purchased_at`,
  );
  const { releases, tracks } = loadMatchInputs(db);
  const match = buildMatcher(releases, tracks);
  const set = db.prepare(`UPDATE bandcamp_item SET release_id = ?, match_state = ? WHERE item_id = ?`);
  const out = { purchases: purchases.length, matched: 0, ambiguous: 0, unmatched: 0 };
  db.transaction(() => {
    for (const p of purchases) {
      up.run(p.itemId, p.url, p.itemType, p.artist, p.title, p.albumTitle, p.primaryGenre, p.purchasedAt);
      const r = match(p);
      out[r.state]++;
      set.run(r.state === 'matched' ? r.releaseId : null, r.state, p.itemId);
    }
  })();
  return out;
}

const pendingSql = `FROM bandcamp_item WHERE match_state='matched' AND page_fetched_at IS NULL AND page_error IS NULL`;

export async function refreshBandcamp(db: Database) {
  const username = env.BANDCAMP_USERNAME?.trim();
  if (!username) return null;
  try {
    const counts = storePurchases(db, await fetchFanCollection(username));
    const { n } = db.prepare(`SELECT COUNT(*) AS n ${pendingSql}`).get() as { n: number };
    return { ...counts, pagesPending: n };
  } catch (e) {
    return { error: e instanceof Error ? e.message : String(e) };
  }
}

let pageLoop: Promise<{ fetched: number; failed: number }> | null = null;

/**
 * Fetch tags for matched items that have none, one page every couple of
 * seconds. Pages are cached forever — a release's tags don't change, and
 * re-fetching a thousand pages every sync is the likeliest way to get blocked.
 * Only matched items are fetched: an unmatched one has nowhere to put its tags.
 */
export function fetchPendingPages(
  db: Database,
  opts: { delayMs?: number; fetcher?: typeof fetchItemPage; limit?: number } = {},
): Promise<{ fetched: number; failed: number }> {
  if (pageLoop) return pageLoop;
  const { delayMs = 2000, fetcher = fetchItemPage, limit = Infinity } = opts;
  pageLoop = (async () => {
    let fetched = 0, failed = 0, backoff = delayMs;
    const next = db.prepare(`SELECT item_id, url, release_id ${pendingSql} LIMIT 1`);
    const ok = db.prepare(`UPDATE bandcamp_item SET tags = ?, primary_genre = COALESCE(?, primary_genre), page_fetched_at = ? WHERE item_id = ?`);
    const bad = db.prepare(`UPDATE bandcamp_item SET page_error = ? WHERE item_id = ?`);
    while (fetched + failed < limit) {
      const row = next.get() as { item_id: string; url: string; release_id: string } | null;
      if (!row) break;
      const { status, html } = await fetcher(row.url);
      if (status === 429) { backoff = Math.min(backoff * 2 || 1000, 300_000); await Bun.sleep(backoff); continue; }
      if (status === 200) {
        const page = parseItemPage(html);
        ok.run(JSON.stringify(page.tags), page.primaryGenre, new Date().toISOString(), row.item_id);
        resolveGenres(db, [row.release_id]);
        fetched++;
        backoff = delayMs;
      } else {
        bad.run(`http ${status}`, row.item_id);
        failed++;
      }
      if (delayMs) await Bun.sleep(delayMs);
    }
    return { fetched, failed };
  })().finally(() => { pageLoop = null; });
  return pageLoop;
}

export function bandcampStatus(db: Database) {
  const c = db.prepare(
    `SELECT COUNT(*) AS purchases,
            SUM(match_state='matched') AS matched, SUM(match_state='ambiguous') AS ambiguous, SUM(match_state='unmatched') AS unmatched
       FROM bandcamp_item`,
  ).get() as Record<string, number | null>;
  const { n } = db.prepare(`SELECT COUNT(*) AS n ${pendingSql}`).get() as { n: number };
  return {
    username: env.BANDCAMP_USERNAME?.trim() || null,
    purchases: c.purchases ?? 0, matched: c.matched ?? 0, ambiguous: c.ambiguous ?? 0, unmatched: c.unmatched ?? 0,
    pagesPending: n,
  };
}
```

```ts
import type { Database } from 'bun:sqlite';
import { PALETTE_SIZE, GENRES } from '$lib/genres';
import { loadVocabulary } from './resolve';

const ranked = (db: Database) =>
  db.prepare(`SELECT name, COUNT(*) AS n FROM release_genre WHERE kind='style' GROUP BY name ORDER BY n DESC, name`).all() as { name: string; n: number }[];

function slotUse(db: Database): number[] {
  const use = Array(PALETTE_SIZE).fill(0);
  for (const r of db.prepare(`SELECT slot FROM style_color`).all() as { slot: number }[]) use[r.slot]++;
  return use;
}
const leastUsed = (use: number[]) => use.indexOf(Math.min(...use));

/**
 * Give every style without a colour one. First run: rank by use so the twelve
 * most common styles each get their own hue. Afterwards a new style takes the
 * least-used slot. Existing colours never move — that's what lets you learn them.
 */
export function assignStyleColors(db: Database): number {
  const have = new Set((db.prepare(`SELECT style FROM style_color`).all() as { style: string }[]).map((r) => r.style));
  const fresh = ranked(db).filter((r) => !have.has(r.name));
  if (!fresh.length) return 0;
  const ins = db.prepare(`INSERT INTO style_color (style, slot) VALUES (?, ?)`);
  db.transaction(() => {
    const use = slotUse(db);
    for (const r of fresh) {
      const slot = leastUsed(use);
      ins.run(r.name, slot);
      use[slot]++;
    }
  })();
  return fresh.length;
}

/** "Reassign by current use": re-rank unpinned styles; pinned ones keep their slot. */
export function reassignStyleColors(db: Database): void {
  db.transaction(() => {
    db.prepare(`DELETE FROM style_color WHERE pinned = 0`).run();
    assignStyleColors(db);
  })();
}

export function pinStyleColor(db: Database, style: string, slot: number): void {
  if (!Number.isInteger(slot) || slot < 0 || slot >= PALETTE_SIZE) throw new Error('bad slot');
  db.prepare(`INSERT INTO style_color (style, slot, pinned) VALUES (?, ?, 1)
              ON CONFLICT(style) DO UPDATE SET slot = excluded.slot, pinned = 1`).run(style, slot);
}

export function listGenreVocabulary(db: Database) {
  const v = loadVocabulary(db);
  const counts = new Map(ranked(db).map((r) => [r.name, r.n]));
  const colors = new Map((db.prepare(`SELECT style, slot, pinned FROM style_color`).all() as { style: string; slot: number; pinned: number }[]).map((r) => [r.style, r]));
  const names = new Set([...v.parents.keys(), ...counts.keys()]);
  return {
    genres: [...GENRES],
    styles: [...names].sort((a, b) => (counts.get(b) ?? 0) - (counts.get(a) ?? 0) || a.localeCompare(b)).map((name) => ({
      name, parents: v.parents.get(name) ?? [], slot: colors.get(name)?.slot ?? null,
      pinned: !!colors.get(name)?.pinned, releases: counts.get(name) ?? 0,
    })),
  };
}
```

```ts
export interface GenreFilter {
  genres?: { include: string[]; exclude: string[] };
  styles?: { include: string[]; exclude: string[] };
  untagged?: boolean;
}

// Repeated params, never comma-joined: "Folk, World, & Country" is one genre.
function split(values: string[]) {
  return {
    include: values.filter((v) => !v.startsWith('-')),
    exclude: values.filter((v) => v.startsWith('-')).map((v) => v.slice(1)),
  };
}

export function parseGenreFilter(params: URLSearchParams): GenreFilter {
  const f: GenreFilter = {};
  const g = params.getAll('genre'), s = params.getAll('style');
  if (g.length) f.genres = split(g);
  if (s.length) f.styles = split(s);
  if (params.get('untagged') === '1') f.untagged = true;
  return f;
}

export function genreFilterToParams(f: GenreFilter, params: URLSearchParams): void {
  for (const v of f.genres?.include ?? []) params.append('genre', v);
  for (const v of f.genres?.exclude ?? []) params.append('genre', `-${v}`);
  for (const v of f.styles?.include ?? []) params.append('style', v);
  for (const v of f.styles?.exclude ?? []) params.append('style', `-${v}`);
  if (f.untagged) params.set('untagged', '1');
}

export function isEmptyGenreFilter(f: GenreFilter): boolean {
  return !f.untagged && !f.genres?.include.length && !f.genres?.exclude.length && !f.styles?.include.length && !f.styles?.exclude.length;
}
```

```ts
import type { GenreFilter } from '$lib/genreFilter';

const inList = (n: number) => Array(n).fill('?').join(',');

/**
 * WHERE fragments over a release id column (`release.id` or `track.release_id`).
 * Includes are any-of. Excludes only ever match tagged releases: "not
 * electronic" means "known to be something else", and untagged records have
 * their own view.
 */
export function genreWhere(col: string, f: GenreFilter | undefined): { where: string[]; params: string[] } {
  const where: string[] = [], params: string[] = [];
  if (!f) return { where, params };
  const tagged = `${col} IN (SELECT release_id FROM release_genre WHERE kind='genre')`;
  for (const kind of ['genre', 'style'] as const) {
    const sel = kind === 'genre' ? f.genres : f.styles;
    if (sel?.include.length) {
      where.push(`${col} IN (SELECT release_id FROM release_genre WHERE kind='${kind}' AND name IN (${inList(sel.include.length)}))`);
      params.push(...sel.include);
    }
    if (sel?.exclude.length) {
      where.push(tagged, `${col} NOT IN (SELECT release_id FROM release_genre WHERE kind='${kind}' AND name IN (${inList(sel.exclude.length)}))`);
      params.push(...sel.exclude);
    }
  }
  if (f.untagged) where.push(`${col} IS NOT NULL AND ${col} NOT IN (SELECT release_id FROM release_genre WHERE kind='genre')`);
  return { where, params };
}

export function stylesByRelease(db: import('bun:sqlite').Database, releaseIds: string[]): Map<string, string[]> {
  const out = new Map<string, string[]>();
  if (!releaseIds.length) return out;

  ).all(...releaseIds) as { release_id: string; name: string }[];
  for (const r of rows) out.set(r.release_id, [...(out.get(r.release_id) ?? []), r.name]);
  return out;
}
```

```ts
interface StyleInfo { name: string; parents: string[]; slot: number | null; pinned: boolean; releases: number }

class GenresStore {
```

```ts
import { GENRES, display } from '$lib/genres';
import type { GenreFilter } from '$lib/genreFilter';

export interface SmartRule {
  genres?: { include: string[]; exclude: string[] };
  styles?: { include: string[]; exclude: string[] };
  starred?: boolean;
}

const strList = (x: unknown): string[] | null =>
  Array.isArray(x) && x.every((s) => typeof s === 'string' && s.trim() && s.length <= 60) ? [...new Set(x as string[])] : null;

function sel(x: unknown, allowed?: readonly string[]) {
  if (x === undefined) return undefined;
  const o = x as { include?: unknown; exclude?: unknown };
  const include = strList(o?.include ?? []), exclude = strList(o?.exclude ?? []);
  if (!include || !exclude) return null;
  if (allowed && [...include, ...exclude].some((g) => !allowed.includes(g))) return null;
  return { include, exclude };
}

export function validateRule(raw: unknown): SmartRule | null {
  if (!raw || typeof raw !== 'object') return null;
  const r = raw as Record<string, unknown>;
  const genres = sel(r.genres, GENRES), styles = sel(r.styles);
  if (genres === null || styles === null) return null;
  if (r.starred !== undefined && typeof r.starred !== 'boolean') return null;
  return { ...(genres && { genres }), ...(styles && { styles }), ...(r.starred && { starred: true }) };
}

export function isEmptyRule(r: SmartRule): boolean {
  return !r.starred && !r.genres?.include.length && !r.genres?.exclude.length && !r.styles?.include.length && !r.styles?.exclude.length;
}

export function ruleToFilter(r: SmartRule): GenreFilter {
  return { genres: r.genres, styles: r.styles };
}

export function ruleSummary(r: SmartRule): string {
  const parts: string[] = [];
  if (r.genres?.include.length) parts.push(r.genres.include.map(display).join(' or '));
  for (const g of r.genres?.exclude ?? []) parts.push(`not ${display(g)}`);
  if (r.styles?.include.length) parts.push(r.styles.include.map(display).join(', '));
  for (const s of r.styles?.exclude ?? []) parts.push(`not ${display(s)}`);
  if (r.starred) parts.push('starred');
  return parts.join(' · ') || 'no rule yet';
}
```

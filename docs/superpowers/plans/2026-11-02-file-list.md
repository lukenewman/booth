# File list (migration step 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Booth keeps one list of the audio files it knows, identified by audio fingerprint, and builds local tracks from that list, with Music.app reduced to a catalog that describes files. The user sees no change.

**Architecture:** Two new tables: one row per audio file (`audio_file`) and one row per catalog listing of a file (`catalog_entry`). A file-list module scans wanted paths with a size+mtime read cache, fingerprints and tag reads included, and detects moved files by catalog id and by fingerprint. The local adapter now emits one track per file, with `externalId` = the file's id and a new `durableId` flag. That flag tells collate to resolve by that id before any weaker key. On the first sync every existing track is matched by its file path and its link is rewritten in place, so track ids, stars, notes, playlists and crates stay put.

**Tech Stack:** Bun, `bun:sqlite`, TypeScript, `music-metadata` (tag reads), ffmpeg (fingerprints, optional), `ulid`.

**Spec:** `docs/superpowers/specs/2026-11-02-migration-and-sources-design.md`, section 1 and build step 1.

## Global Constraints

- **No visible change.** Track ids, titles, artists, albums, release ids, release grouping, stars, notes, playlist and crate rows are identical before and after. Names keep coming from Music.app where it lists a file. Switching names to the file's own tags is step 3, with "sources disagree" findings. Measured 2026-11-02: tags and Music.app differ on year for 127 files, title 5, album 6, track number 5, and some files carry no tags at all.
- **Links and facets stay under the source id `local`.** Splitting facets per catalog (`music`, `rekordbox`) is step 3. Eleven readers depend on `source='local'` today.
- **Prune behaviour is unchanged in this step.** A track Music.app stops listing is still pruned as it is today, and a file deleted from Booth's folder still removes its track. Replacing both with findings is step 2.
- **Vinyl rips are untouched.** They keep their path external ids and the recordings-root prune guard. Registering them in the file list is step 2.
- **ffmpeg is optional** (landing page: `brew install ffmpeg` is an optional step). With no ffmpeg, sync works and fingerprints are null.
- **Never write to an audio file.** This step only reads.
- Migration number: `018`.
- Verify scripts run with `bun verify scripts/<name>.ts`, use in-memory or temp-dir databases, and never touch `~/.booth`.
- Commits go to `main`, reference BOO-101, and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **ffmpeg not installed.** Sync completes, every file is registered with a null fingerprint, nothing throws, and once ffmpeg appears the next sync fingerprints the files it skipped. Pinned in Task 2.
2. **A file that can't be read** (corrupt, permission refused by macOS's Music-folder prompt, zero bytes). It's registered with null tags, the sync doesn't fail, and a catalog-listed track for it is still emitted with Music.app's names. Pinned in Tasks 2 and 4.
3. **The first scan is interrupted** (app quit while fingerprinting 4,400 files). The next sync resumes without duplicate rows, and files already registered keep their ids. Pinned in Task 2.
4. **The same file is reached twice**: listed by Music.app *and* inside Booth's folder, or listed twice by Music.app. That gives one track, and a second sync makes no conflicts and no relinks. Pinned in Task 4.
5. **Music.app renames a folder after a retag.** Same Persistent ID, new location. The track keeps its id, its playlist rows and its star, and its file-path key follows. Pinned in Task 4; the fingerprint-only variant (Persistent ID changed too) is pinned in Task 2.

```sql
-- One row per audio file Booth knows about, wherever it lives. The track a
-- file backs is found through the local source_link, whose external_id is this
-- row's id. Identity across moves is the fingerprint: a hash of the coded audio
-- stream, unchanged by tag writes and renames.
--
-- size and mtime_ms are those of the last read; a file whose size and mtime
-- still match is not read again. fingerprint_tried is 1 once ffmpeg has had a
-- go (success or a per-file failure), so an unfingerprintable file isn't
-- retried every sync; it stays 0 when ffmpeg was missing, so the file is
-- fingerprinted once ffmpeg turns up.
CREATE TABLE audio_file (
  id                TEXT PRIMARY KEY,
  path              TEXT NOT NULL UNIQUE,
  fingerprint       TEXT,
  fingerprint_tried INTEGER NOT NULL DEFAULT 0,
  size              INTEGER,
  mtime_ms          INTEGER,
  tags              TEXT,
  ownership         TEXT NOT NULL DEFAULT 'in_place' CHECK (ownership IN ('in_place', 'booth')),
  present           INTEGER NOT NULL DEFAULT 1,
  missing_since     TEXT,
  first_seen_at     TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  last_seen_at      TEXT
);
CREATE INDEX audio_file_fingerprint ON audio_file(fingerprint);

-- A catalog (Music.app today, rekordbox later) listing a file under its own id.
-- The catalog's id is what recognises a file the catalog itself moved, such
-- as Music.app renaming a folder after a retag.
CREATE TABLE catalog_entry (
  catalog    TEXT NOT NULL,
  catalog_id TEXT NOT NULL,
  file_id    TEXT NOT NULL REFERENCES audio_file(id) ON DELETE CASCADE,
  location   TEXT NOT NULL,
  seen_at    TEXT NOT NULL,
  PRIMARY KEY (catalog, catalog_id)
);
CREATE INDEX catalog_entry_file ON catalog_entry(file_id);
```

```ts
import type { Database } from 'bun:sqlite';
import { existsSync, statSync } from 'node:fs';
import { ulid } from 'ulid';
import { FfmpegMissingError } from '../analysis/decode';
import type { FileTags } from './tags';

/**
 * The file list: every audio file Booth knows about, wherever it lives.
 *
 * A track is one of these files (its local source_link's external_id is the
 * row id), so the row's id must survive everything that happens to a file:
 * retags, renames, moves. Two things carry identity across a move: a catalog's
 * own id for the file (see catalogs.ts) and the audio fingerprint here. A new
 * path whose fingerprint matches exactly one file that has gone missing, and
 * whose old path nobody still asks for, is that file moved.
 *
 * Reads are cached on size + mtime. A file whose size and mtime still match is
 * not touched, which is what keeps a 4,400-file sync to a round of stat calls.
 * Rows are written as each batch finishes, so an interrupted first scan picks
 * up where it stopped.
 *
 * This module only reads audio files. It never writes one.
 */

export type Ownership = 'in_place' | 'booth';

export interface FileRow {
  id: string;
  path: string;
  fingerprint: string | null;
  tags: FileTags | null;
  ownership: Ownership;
  present: boolean;
}

export interface FileListDeps {
  fingerprint(path: string): Promise<string>;
  readTags(path: string): Promise<FileTags>;
}

export interface FileScanSummary {
  /** Distinct paths asked for. */
  known: number;
  /** Files whose tags or fingerprint were read this scan. */
  read: number;
  /** Files recognised at a new path. */
  moved: number;
  /** Paths asked for with no file behind them. */
  missing: number;
  /** ffmpeg was not available, so nothing was fingerprinted. */
  fingerprintsUnavailable: boolean;
  unreadable: { path: string; error: string }[];
}

interface DbRow {
  id: string;
  path: string;
  fingerprint: string | null;
  fingerprint_tried: number;
  size: number | null;
  mtime_ms: number | null;
  tags: string | null;
  ownership: Ownership;
  present: number;
}

interface Job {
  path: string;
  ownership: Ownership;
  size: number;
  mtimeMs: number;
  row: DbRow | null;
  /** Tags are still good; only the fingerprint is owed. */
  fingerprintOnly: boolean;
}

const BATCH = 4;
const now = () => new Date().toISOString();

function toFileRow(r: DbRow): FileRow {
  return {
    id: r.id,
    path: r.path,
    fingerprint: r.fingerprint,
    tags: r.tags ? (JSON.parse(r.tags) as FileTags) : null,
    ownership: r.ownership,
    present: r.present === 1,
  };
}

export function fileByPath(db: Database, path: string): FileRow | null {
  const r = db.prepare(`SELECT * FROM audio_file WHERE path = ?`).get(path) as DbRow | null;
  return r ? toFileRow(r) : null;
}

export async function scanFiles(
  db: Database,
  wanted: { path: string; ownership: Ownership }[],
  deps: FileListDeps,
): Promise<{ files: Map<string, FileRow>; summary: FileScanSummary }> {
  const summary: FileScanSummary = { known: 0, read: 0, moved: 0, missing: 0, fingerprintsUnavailable: false, unreadable: [] };

  // A path wanted as Booth-owned anywhere is Booth-owned.
  const ownershipOf = new Map<string, Ownership>();
  for (const w of wanted) {
    if (ownershipOf.get(w.path) !== 'booth') ownershipOf.set(w.path, w.ownership);
  }
  summary.known = ownershipOf.size;

  const byPath = db.prepare(`SELECT * FROM audio_file WHERE path = ?`);
  const jobs: Job[] = [];

  for (const [path, ownership] of ownershipOf) {
    const row = byPath.get(path) as DbRow | null;
    let st: { size: number; mtimeMs: number } | null = null;
    try {
      const s = statSync(path);
      if (s.isFile()) st = { size: s.size, mtimeMs: Math.floor(s.mtimeMs) };
    } catch {
      st = null;
    }

    if (!st) {
      summary.missing++;
      if (row) {
        db.prepare(`UPDATE audio_file SET present = 0, missing_since = COALESCE(missing_since, ?), ownership = ? WHERE id = ?`)
          .run(now(), ownership, row.id);
      } else {
        db.prepare(`INSERT INTO audio_file (id, path, ownership, present, missing_since) VALUES (?, ?, ?, 0, ?)`)
          .run(ulid(), path, ownership, now());
      }
      continue;
    }

    const unchanged = row && row.size === st.size && row.mtime_ms === st.mtimeMs;
    if (unchanged && (row.fingerprint !== null || row.fingerprint_tried === 1)) {
      db.prepare(`UPDATE audio_file SET present = 1, missing_since = NULL, ownership = ?, last_seen_at = ? WHERE id = ?`)
        .run(ownership, now(), row.id);
      continue;
    }
    jobs.push({ path, ownership, size: st.size, mtimeMs: st.mtimeMs, row, fingerprintOnly: !!unchanged });
  }

  for (let i = 0; i < jobs.length; i += BATCH) {
    const done = await Promise.all(jobs.slice(i, i + BATCH).map((job) => readJob(job, deps, summary)));
    db.transaction(() => {
      for (const d of done) writeJob(db, d, ownershipOf, summary);
    })();
  }

  const files = new Map<string, FileRow>();
  for (const path of ownershipOf.keys()) {
    const r = byPath.get(path) as DbRow | null;
    if (r) files.set(path, toFileRow(r));
  }
  return { files, summary };
}

interface ReadResult extends Job {
  tags: string | null;
  fingerprint: string | null;
  fingerprintTried: number;
}

async function readJob(job: Job, deps: FileListDeps, summary: FileScanSummary): Promise<ReadResult> {
  let tags: string | null = job.fingerprintOnly ? job.row!.tags : null;
  if (!job.fingerprintOnly) {
    try {
      tags = JSON.stringify(await deps.readTags(job.path));
    } catch (e) {
      summary.unreadable.push({ path: job.path, error: e instanceof Error ? e.message : String(e) });
    }
  }

  let fingerprint: string | null = null;
  let fingerprintTried = 0;
  if (!summary.fingerprintsUnavailable) {
    try {
      fingerprint = await deps.fingerprint(job.path);
      fingerprintTried = 1;
    } catch (e) {
      if (e instanceof FfmpegMissingError) {
        summary.fingerprintsUnavailable = true;
      } else {
        fingerprintTried = 1;
        if (tags !== null) summary.unreadable.push({ path: job.path, error: e instanceof Error ? e.message : String(e) });
      }
    }
  }
  summary.read++;
  return { ...job, tags, fingerprint, fingerprintTried };
}

function writeJob(db: Database, d: ReadResult, wanted: Map<string, Ownership>, summary: FileScanSummary): void {
  const stamp = now();
  if (d.row) {
    db.prepare(
      `UPDATE audio_file SET size = ?, mtime_ms = ?, tags = ?, fingerprint = ?, fingerprint_tried = ?,
              ownership = ?, present = 1, missing_since = NULL, last_seen_at = ? WHERE id = ?`,
    ).run(d.size, d.mtimeMs, d.tags, d.fingerprint, d.fingerprintTried, d.ownership, stamp, d.row.id);
    return;
  }

  // A new path. Is it a file we already know, moved? Only if exactly one
  // known file has this audio, nobody still asks for its old path, and
  // nothing is there any more. A copy turning up beside a present original
  // is a duplicate, never a move.
  if (d.fingerprint) {
    const candidates = (db
      .prepare(`SELECT id, path FROM audio_file WHERE fingerprint = ?`)
```

```ts
import type { Database } from 'bun:sqlite';
import type { FileRow } from './fileList';

/**
 * What catalogs (Music.app now, rekordbox later) say about where files are.
 *
 * A catalog never creates a track. It lists files by location under its own
 * id, and that id is the cheapest way to recognise a file the catalog moved:
 * Music.app renames folders when tags change, and its Persistent ID stays put.
 * Fingerprints (fileList.ts) cover the same case when a catalog's id churns
 * too.
 */

export interface CatalogRef {
  catalogId: string;
  path: string;
}

/**
 * Before scanning: where a catalog lists a known id at a new location, carry
 * the file row to that location. Refused when another file already holds the
 * new path, or when the row has already moved away from where this catalog
 * last saw it. Returns how many rows moved.
 */
export function applyCatalogMoves(db: Database, catalog: string, refs: CatalogRef[]): number {
  const prevOf = db.prepare(
    `SELECT ce.location, f.id AS fileId, f.path
       FROM catalog_entry ce JOIN audio_file f ON f.id = ce.file_id
      WHERE ce.catalog = ? AND ce.catalog_id = ?`,
  );
  const taken = db.prepare(`SELECT 1 FROM audio_file WHERE path = ?`);
  const move = db.prepare(`UPDATE audio_file SET path = ? WHERE id = ?`);

  let moved = 0;
  db.transaction(() => {
    for (const r of refs) {
      const prev = prevOf.get(catalog, r.catalogId) as { location: string; fileId: string; path: string } | null;
      if (!prev || prev.location === r.path) continue;
      if (prev.path !== prev.location) continue;
      if (taken.get(r.path)) continue;
      move.run(r.path, prev.fileId);
      moved++;
    }
  })();
  return moved;
}

/**
 * After scanning: record which file each listing points at, and forget
 * listings this catalog no longer has. The file rows themselves stay.
 */
export function recordCatalogEntries(
  db: Database,
  catalog: string,
  refs: CatalogRef[],
  files: Map<string, FileRow>,
): void {
  const stamp = new Date().toISOString();
  const upsert = db.prepare(
    `INSERT INTO catalog_entry (catalog, catalog_id, file_id, location, seen_at) VALUES (?, ?, ?, ?, ?)
     ON CONFLICT(catalog, catalog_id) DO UPDATE SET file_id = excluded.file_id, location = excluded.location, seen_at = excluded.seen_at`,
  );
  db.transaction(() => {
    for (const r of refs) {
      const file = files.get(r.path);
      if (file) upsert.run(catalog, r.catalogId, file.id, r.path, stamp);
    }
    db.prepare(`DELETE FROM catalog_entry WHERE catalog = ? AND seen_at <> ?`).run(catalog, stamp);
  })();
}
```

```ts
 * Tracks for files in Booth's folder that no catalog lists, built from their
 * own tags. The file list (library/fileList.ts) has already read and cached
 * the tags; this only shapes them.
 *
 * Emitted as part of the local source's normal result rather than written
 * directly, which is what keeps them safe: a track present in the sync result
 * is never pruned. Deleting a file from the tree still removes its track.
 */
export function ingestedFromFiles(
  files: FileRow[],
  groupIdFor: (tags: FileTags) => string | undefined,
): { releases: SourceRelease[]; tracks: SourceTrack[] } {
  const tracks: SourceTrack[] = [];
  const releaseOf = new Map<string, SourceRelease>();

  for (const file of files) {
    const tags = file.tags;
    if (!file.present || !tags) continue;
    const releaseExternalId = groupIdFor(tags);
    const artist = (tags.albumArtist ?? tags.artist ?? '').trim();

    if (releaseExternalId && !releaseOf.has(releaseExternalId)) {
      releaseOf.set(releaseExternalId, {
        externalId: releaseExternalId,
        title: tags.album!,
        artist,
        year: tags.year,
        facets: { origin: 'download' },
      });
    }

    tracks.push({
      externalId: file.id,
      durableId: true,
      title: tags.title ?? file.path.split('/').pop()!,
      artist: (tags.artist ?? artist).trim(),
      album: tags.album,
      durationMs: tags.durationMs,
      position: tags.trackNumber != null ? String(tags.trackNumber) : undefined,
      filePath: file.path,
      releaseExternalId,
      facets: pickDefined({
        origin: 'download',
        [DATE_ADDED_KEY]: acquiredAt(file.path),
        [DATE_ADDED_ORIGIN_KEY]: 'witnessed',
        bpm: tags.bpm,
        genre: tags.genre,
        bandcampHost: bandcampHostFrom(tags.comment),
        rating: tags.rating,
      }),
    });
  }

  return { releases: [...releaseOf.values()], tracks };
```

```ts
 * Booth's folder that no catalog lists is built from its tags.
 *
 * Catalog-listed files that are missing on disk are still emitted, as they
 * were before, so their tracks and everything attached to them stay.
 */

export interface CatalogTrack {
  catalogId: string;
  /** Absolute path, already decoded from the catalog's URL form. */
  path: string;
  track: Omit<SourceTrack, 'externalId' | 'filePath' | 'durableId'>;
}

export interface Catalog {
  id: string;
  tracks: CatalogTrack[];
  releases: SourceRelease[];
}

export interface LocalResult {
  tracks: SourceTrack[];
  releases: SourceRelease[];
  files: FileScanSummary;
  /** Tracks built from Booth's folder rather than a catalog. */
  boothTracked: number;
}

export async function buildLocalResult(
  db: Database,
  input: { catalogs: Catalog[]; boothFiles: string[]; groupIdFor: (t: FileTags) => string | undefined },
  deps: FileListDeps,
): Promise<LocalResult> {
  const refsOf = (c: Catalog): CatalogRef[] => c.tracks.map((t) => ({ catalogId: t.catalogId, path: t.path }));

  let catalogMoves = 0;
  for (const c of input.catalogs) catalogMoves += applyCatalogMoves(db, c.id, refsOf(c));

  const wanted = [
    ...input.catalogs.flatMap((c) => c.tracks.map((t) => ({ path: t.path, ownership: 'in_place' as const }))),
    ...input.boothFiles.map((path) => ({ path, ownership: 'booth' as const })),
  ];
  const { files, summary } = await scanFiles(db, wanted, deps);
  summary.moved += catalogMoves;
  for (const c of input.catalogs) recordCatalogEntries(db, c.id, refsOf(c), files);

  const tracks: SourceTrack[] = [];
  const releases = new Map<string, SourceRelease>();
  const emitted = new Set<string>();

  for (const c of input.catalogs) {
    for (const r of c.releases) if (!releases.has(r.externalId)) releases.set(r.externalId, r);
    for (const ct of c.tracks) {
      const file = files.get(ct.path);
      if (!file || emitted.has(file.id)) continue;
      emitted.add(file.id);
      tracks.push({ ...ct.track, externalId: file.id, durableId: true, filePath: file.path });
    }
  }

  const unlisted = input.boothFiles
    .map((path) => files.get(path))
    .filter((f): f is NonNullable<typeof f> => !!f && !emitted.has(f.id));
  const ingested = ingestedFromFiles(unlisted, input.groupIdFor);
  tracks.push(...ingested.tracks);
  for (const r of ingested.releases) if (!releases.has(r.externalId)) releases.set(r.externalId, r);

  return { tracks, releases: [...releases.values()], files: summary, boothTracked: ingested.tracks.length };
}
```

```ts
import { Database } from 'bun:sqlite';
import { mkdtempSync } from 'node:fs';

import { join } from 'node:path';

const scratch = mkdtempSync(join(tmpdir(), 'booth-switch-'));
const copy = join(scratch, 'booth.db');
const real = process.env.BOOTH_REAL_DB ?? join(homedir(), '.booth', 'booth.db');
const proc = Bun.spawnSync(['sqlite3', real, `.backup '${copy}'`]);
if (proc.exitCode !== 0) throw new Error(`backup failed: ${proc.stderr.toString()}`);

const db = getDb();

function snapshot() {
  const q = <T>(sql: string) => db.prepare(sql).all() as T[];
  return {
    tracks: q<{ id: string; title: string; album: string | null; release_id: string | null; position: string | null; starred_at: string | null; note: string | null }>(
      `SELECT id, title, album, release_id, position, starred_at, note FROM track ORDER BY id`),
    releases: q<{ id: string; title: string; artist_id: string; year: number | null }>(`SELECT id, title, artist_id, year FROM release ORDER BY id`),
    playlistTracks: q<{ id: string; track_id: string | null }>(`SELECT id, track_id FROM playlist_track ORDER BY id`),
    playlistReleases: q<{ id: string; release_id: string | null }>(`SELECT id, release_id FROM playlist_release ORDER BY id`),
    filePaths: q<{ entity_id: string; key_value: string }>(`SELECT entity_id, key_value FROM match_key WHERE entity_kind='track' AND key_type='file_path' ORDER BY entity_id`),
  };
}

function diff(label: string, a: unknown[], b: unknown[]): number {
  const as = new Set(a.map((x) => JSON.stringify(x)));
  const bs = new Set(b.map((x) => JSON.stringify(x)));
  const gone = [...as].filter((x) => !bs.has(x));
  const added = [...bs].filter((x) => !as.has(x));
  if (gone.length || added.length) {
    console.log(`✗ ${label}: ${gone.length} gone, ${added.length} new`);
    for (const g of gone.slice(0, 5)) console.log(`   - ${g}`);
    for (const n of added.slice(0, 5)) console.log(`   + ${n}`);
  } else console.log(`✓ ${label}: unchanged (${a.length})`);
  return gone.length + added.length;
}

console.log(`\ncopy kept at ${copy}`);
```
